# Weather App

## Description
A Python program that fetches and displays real-time weather data for any city using the OpenWeatherMap API.

## How to Run
1. Open terminal
2. Navigate to the `Task4_Weather_App` folder
3. Run: `python weather.py`

## Features
- Enter any city name
- Displays current temperature in Celsius
- Shows weather description (e.g., clear sky, rain)
- Displays humidity percentage
- Displays wind speed
- Error handling for invalid city names
